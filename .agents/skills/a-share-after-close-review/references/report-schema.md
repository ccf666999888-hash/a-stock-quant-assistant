# HTML Report Contract

The report is a self-contained UTF-8 HTML file with embedded images.

Required sections:

1. One-sentence conclusion and actual trading date
2. Market regime, provider-labeled market-flow state, limit-up/broken-board/limit-down ecology, recent emotion history, and a Shanghai Composite 60-minute K-line/MACD chart covering the latest 60 calendar days
3. All tracked sectors with state, score, breadth, relative strength, provider-labeled flow, limit-event ecology, momentum, outlook, and next-session plan
4. Expanded 60-minute K-line cards covering the same latest-60-calendar-day window, only for sectors classified as `抄底观察`
5. High-open, flat-open, and low-open market scenarios
6. Priority stock watchlist
7. Conditional stock watchlist
8. A separate non-one-word first-board relay observation pool
9. Data quality, unavailable fields, provider definitions, methodology limitations, and risk statement

Each ordinary stock row includes code, name, sector, sector and stock states, score, key volume-price metrics, flow source and state, support, reasons, risks, and cancellation conditions. Each first-board row includes sealing times, open count, seal-to-float ratio, turnover, fund-flow source and state, risks, and next-session cancellation conditions.

Use `等待确认`, `不追高`, `回踩观察`, `取消观察`, and `降级为回避`. Do not use guaranteed-return language.
