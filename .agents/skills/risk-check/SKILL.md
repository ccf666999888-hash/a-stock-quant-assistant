# Risk Check

1. Run `scripts/run.py --trade-date YYYYMMDD`.
2. Return the risk stock list, risk types, numeric deductions, and avoidance reasons.
3. Distinguish severe risk from ordinary caution.
4. Never turn absence of a triggered rule into a guarantee of safety.
