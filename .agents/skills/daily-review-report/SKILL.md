# Daily Review Report

1. Ensure screening results exist for the requested date.
2. Run `scripts/run.py --trade-date YYYYMMDD`.
3. Include market state, index changes, observation pools, support/resistance, scenarios, and risks.
4. Clearly state that the report does not constitute investment advice.
